- Статус: готово, не выпущено (2026-11-21). Аудит влит (сервер `d82838d95`, клиенты — PR #23–#26, #19). Решения владельца 2026-11-21 (ниже, «Решения владельца») — сервер `task/118b-owner-decisions`, клиенты `task/118b-<клиент>-owner-decisions`; не влито, не запушено.

## Что сделано
1. Аудит каждого клиента только чтением: патч `ci/patch.py` из `origin/main` наложен на чистую копию закреплённого апстрима, просканированы литералы цветов (оттенок синих Telegram), провайдеры тем, ресурсы, SVG, Lottie и английские строки, которые код пишет мимо ключей.
2. Исправления в патчах клиентов — по находке на правку, у каждой правки проверка в `verify` и тесты.
3. Новые ключи переведены на сервере (`pkg/langpack/own.json`, `patchkeys.json`, 42 языка); ссылки, которые патчи поменяли во встроенном английском, переписываются и в пакетах всех языков (`rebrand.go`).
4. Независимая сверка: тесты патчей каждого клиента прогнаны ещё раз, ключи сверены с сервером; найденный разрыв (множественный ключ Web K, который сервер не может отдать) исправлен.

## Что было с меню звонка
Самая вероятная причина жалобы — **Android**: групповой звонок и конференция рисуют меню участника, строки «Добавить людей»/«Поделиться ссылкой», кнопки, чекбоксы и все листы, которые открывают, через `DarkBlueThemeResourcesProvider` (`ui/GroupCallActivity.java:1888`) и его базу `Stories/DarkThemeResourceProvider`; патч их не трогал — фон меню `#303B47`, кнопки `#1A9CFF`. Теперь A-131. На iOS из звонков торчали статус «говорит» (зелёный Telegram) и синяя кнопка «Отправить» чата звонка (I-135); на Desktop — серые Telegram с синевой в отключённых пунктах, шорткатах и стрелке подменю меню звонка (D-108); на Web K — серые Telegram у панели группового звонка (W-088).

## Сверка (шаг 3)
- `Pluma.Scheduled.SendNow.Many` в патче Web K был множественным (`one_value`/`other_value`), а сервер отдаёт свои строки только простыми (`pkg/langpack/own.go`, `own.json`: `{pack: {key: {lang: text}}}`): пакет заменил бы множественную строку простой. Ключ сделан простым «Send %d messages now?» — он нужен только для двух сообщений и больше; в языках, где у 2+ несколько форм (ru, uk, be, pl, cs, sk, hr, sr, sl, lt, lv, ar, he, ro), перевод даёт число в скобках.
- Встроенный английский Desktop и Web K с `pluma.chat` расходился бы с пакетами других языков — закрыто правилами `rebrand.go`.
- Тесты патчей всех клиентов прогнаны ещё раз на Mac (цифры — в «Результате»).

## Результат

# 118. Цвета Pluma и переводы везде: аудит четырёх клиентов и исправления

- Статус: готово, не влито и не выпущено (2026-11-21). Сервер — ветка `task/118-colors-l10n`; клиенты — ветки `task/118-<клиент>-colors-l10n` (ниже), не запушены.
- Поставлена владельцем 2026-11-21: «сам звонок не проверял, но цвета телеграмовские в меню. проверь клиенты на цвета во всех местах, а также проверь во всех местах то, что переводы есть везде, где надо. что нет хардкода/места, где перевод не применяется. должно быть идеально чётко во всём».
- Зависит от: палитры Pluma (ADR 0025 бренд, `CALL_COLORS` звонков, фон звонков вариант A — шалфей), 114 (свои строки во всех пакетах и языках, ADR 0046), 117 (конференции).
- Клиенты (`upstream.env`): Android DrKLO 13.2.1 `7be672ea`, iOS release-13.2 `24638bc6`, tdesktop v7.4.1 `157f5cfc`, tweb `aa74832e` (2.3/686).

## Что сделано
1. Аудит каждого клиента только чтением: патч `ci/patch.py` из `origin/main` наложен на чистую копию закреплённого апстрима, просканированы литералы цветов (оттенок синих Telegram), провайдеры тем, ресурсы, SVG, Lottie и английские строки, которые код пишет мимо ключей.
2. Исправления в патчах клиентов — по находке на правку, у каждой правки проверка в `verify` и тесты.
3. Новые ключи переведены на сервере (`pkg/langpack/own.json`, `patchkeys.json`, 42 языка); ссылки, которые патчи поменяли во встроенном английском, переписываются и в пакетах всех языков (`rebrand.go`).
4. Независимая сверка: тесты патчей каждого клиента прогнаны ещё раз, ключи сверены с сервером; найденный разрыв (множественный ключ Web K, который сервер не может отдать) исправлен.

## Что было с меню звонка
Самая вероятная причина жалобы — **Android**: групповой звонок и конференция рисуют меню участника, строки «Добавить людей»/«Поделиться ссылкой», кнопки, чекбоксы и все листы, которые открывают, через `DarkBlueThemeResourcesProvider` (`ui/GroupCallActivity.java:1888`) и его базу `Stories/DarkThemeResourceProvider`; патч их не трогал — фон меню `#303B47`, кнопки `#1A9CFF`. Теперь A-131. На iOS из звонков торчали статус «говорит» (зелёный Telegram) и синяя кнопка «Отправить» чата звонка (I-135); на Desktop — серые Telegram с синевой в отключённых пунктах, шорткатах и стрелке подменю меню звонка (D-108); на Web K — серые Telegram у панели группового звонка (W-088).

## Сверка (шаг 3)
- `Pluma.Scheduled.SendNow.Many` в патче Web K был множественным (`one_value`/`other_value`), а сервер отдаёт свои строки только простыми (`pkg/langpack/own.go`, `own.json`: `{pack: {key: {lang: text}}}`): пакет заменил бы множественную строку простой. Ключ сделан простым «Send %d messages now?» — он нужен только для двух сообщений и больше; в языках, где у 2+ несколько форм (ru, uk, be, pl, cs, sk, hr, sr, sl, lt, lv, ar, he, ro), перевод даёт число в скобках.
- Встроенный английский Desktop и Web K с `pluma.chat` расходился бы с пакетами других языков — закрыто правилами `rebrand.go`.
- Тесты патчей всех клиентов прогнаны ещё раз на Mac (цифры — в «Результате»).

## Решения к подтверждению
1. Web K: плитка без видео в групповом звонке `#232623` (ночной фон сообщения; точного цвета в палитре нет).
2. Web K: вопрос «Отправить сейчас» для нескольких сообщений — с числом в скобках в языках со сложным множественным числом.
3. Desktop: `lng_pluma_*` для текстов `Lang::Hard` с английским апстрима («Pluma Passport» в текстах паспорта).
4. Android: «Generate Invite Link» → «Create Invite Link» (ключ апстрима той же кнопки).
5. Ждут владельца (не делались): папки «Telegram» при сохранении (Android), темы «Day»/«Night» Desktop, градиент Premium, тосты с сырыми кодами ошибок по Desktop.

## Результат
Аудит нашёл цвета Telegram, которые патчи не покрывали, во всех четырёх клиентах; главный источник «телеграмовского меню звонка» — тёмные провайдеры Android, через которые рисуются меню и листы группового звонка и конференции. Все видимые и редкие находки, не требующие решения владельца, исправлены в патчах с проверками; английские тексты, которые клиенты писали мимо перевода, заменены ключами апстрима или новыми ключами Pluma, переведёнными сервером на 42 языка.
- Тесты (Mac, `python3 -I ci/patch_test.py` с `./upstream`): Android — 158 OK; iOS — 157 OK (свежая разреженная выборка); Desktop — 147 OK (`./upstream` — разреженная выборка 157f5cfc, 15 мин); Web K — 79 OK (36 мин; после правки `Pluma.Scheduled.SendNow.Many`, коммит web `1948f0e`).
- Сервер: JSON проверен `python3 -I` (42 языка у каждого ключа, ключи = `patchkeys.json`, аргументы совпадают с английским), `gofmt -l` пуст.

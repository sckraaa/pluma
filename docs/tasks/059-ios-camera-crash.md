# 059. iOS: вылет при открытии камеры из скрепки

- Статус: todo (2026-11-07), нужен отчёт о сбое
- Зависит от: —

## Цель
Камера из меню скрепки в диалоге открывается на iOS и снимает фото и видео, как в Telegram.

## Что известно
- **Отчёт владельца 2026-11-07:** в диалоге «скрепка → камера» приложение падает.
- Подозрение (не проверено): наш патч ITMS-91198 убирает из сборки шрифты камеры AremacFS (`ci/patch.py`, `CAMERA_FONTS`); загрузка шрифта в `Display/Source/Font.swift` переведена на системный при отсутствии. Других мест загрузки этих шрифтов поиск по исходникам не нашёл, поэтому причина может быть иной. Ключ `NSCameraUsageDescription` в Info.plist есть (`upstream/Telegram/BUILD:1619`).
- Без отчёта о сбое причину не установить: нужен файл из «Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики» (запись с именем приложения и датой сбоя), либо воспроизведение на устройстве. В симуляторе камеры нет.

## Область
- Получить отчёт о сбое, найти причину, исправить патчем клиента (строка в реестре iOS).
- Проверить и снимок, и видео, и кружок из той же камеры.

## Критерии приёмки
- На устройстве со скриншотами: камера из скрепки открывается, фото и видео отправляются.

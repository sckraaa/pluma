# 074. Обновление версий клиентов до слоя 233

- Статус: in progress (исследование готово 2026-11-09, `docs/tasks/074-research/`)
- Зависит от: партий 2026-11-09
- ADR: 0008 заменяется новым (сервер обслуживает несколько слоёв сразу), 0009 (порядок обновления кодека).

## Цель
Android, iOS, Desktop и Web на свежих версиях. Для Android это важно пользователям: новый интерфейс и новая запись кружков (`InstantCameraView2`, пауза, предпросмотр, обрезка).

|---|---|---|---|---|
| Android | 12.9.1 | 13.2.1 (`7be672ea`) | 233 | 28 из 828 |
| iOS | 12.9.2 | 13.2 (`24638bc6`) | 233 | 31 из 415 |
| Desktop | 7.0.9 | 7.4.1 (`157f5cfc`) | 233 | 20 из 191 |

- **Клиент отдельно от сервера обновить нельзя:** из 210 новых конструкторов сервер знает 5, например `inputReplyToMessage` сменился, и ответы перестанут декодироваться.
- **`teamgram/proto` есть только до слоя 231,** генератора `mtprotoc` нет: 232 и 233 нужны своим способом.
- Кодек умеет несколько слоёв, но ошибки Encode проглатываются, а пуши строятся один раз на всех: это чинить до смешанного режима.
- Сборка: Android — 19 субмодулей, SDK 36, CMake 3.22; iOS — Xcode 27.1 (на GitHub пока preview), Bazel 9.2; Desktop — обновления v2, Rust; Web — tiptap.

## План
1. Сервер: слой 233 при сохранении клиентов 228 (выкатывается первым, текущие клиенты продолжают работать).
2. Клиенты по одному: Android первым, затем Desktop, Web, iOS (когда доступен Xcode 27.1).
3. Новые функции слоёв 229–233 — отдельные задачи.

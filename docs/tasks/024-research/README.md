# Задача 024: исследование (2026-11-02)

Заметки на английском, с цитатами по файлам и строкам. Они собраны перед проектированием импорта. Решения по ним записываются в бриф и в ADR задачи 024.

- `server.md` — что отвечают нужные методы сейчас, как маршрутизируются, как хранятся и раздаются документы (таблицы `documents`/`photo_sizes`/`video_sizes`, dfs, `upload.getFile`), почему нынешние пути загрузки не подходят для импорта.
- `semantics.md` — семантика методов по core.telegram.org и коду клиентов: `hash` и `NotModified`, частота запросов, особые наборы стикеров, что нужно клиентам для реакций и эффектов.
- `collect.md` — выгрузка через уже открытую сессию Web K (`invokeApi`, `upload.getFile` без преобразований, ссылки на файлы, приёмник на 127.0.0.1, темп).
- `critique.md` — проверка шести ключевых утверждений и список того, чего не хватает для проекта.

Ссылки на строки клиентов даны по локальным копиям; для закреплённых версий (`upstream.env` клиентов) их нужно перепроверить.

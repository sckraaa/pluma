# 072. Панель управления Pluma

- Статус: todo (объём согласован владельцем 2026-11-09; начать после партии 5 и 071)
- Зависит от: 025 (панель модерации), 071 (Premium для всех: раздел Premium убирается), 073 (коды входа: настройка регистрации)
- ADR: 0040 (сеть и вход не меняются); новый, если меняется модель данных панели.

## Цель
Панель — пульт управления всем Pluma; SSH нужен только в аварии. Сейчас в ней только модерация (279 строк интерфейса).

## Решения владельца (2026-11-09)
- Объём: все разделы ниже, двумя шагами.
- В панели работает только владелец: **ролей нет** (`admin_users` остаётся как список входа, разделение прав убрать).
- Удаление аккаунта и канала — не сразу: сначала блокировка, удаление отдельным подтверждением ключом доступа.
- Панель удобна и на телефоне.

## Область
**Шаг 1**
- **Обзор:** пользователи, в сети, сообщения за сутки, регистрации, диск, проблемы сервисов, новые жалобы.
- **Пользователи:** поиск по номеру, имени, `@username`, id. Карточка: профиль, устройства, ограничения, жалобы. Действия: завершить сессии, ограничить, заблокировать, снять, показать код входа, написать от Pluma, удалить аккаунт.
- **Каналы и группы:** поиск, карточка (владелец, участники, жалобы), заблокировать, удалить.
- **Жалобы:** переделать удобнее: очередь, снимок, решение в один клик.
- **Регистрация:** переключатель «открыта / по списку», управление списком номеров (073).

**Шаг 2**
- **Рассылка** от служебного аккаунта всем или группе пользователей.
- **Выпуски:** версии клиентов на сайте, выпустить, откатить.
- **Система:** состояние сервисов, зависшие события с «повторить» и «отбросить», ссылки на Grafana.
- **Журнал и доступ.**

## Правила
- Панель никогда не показывает переписку: только снимки того, на что пожаловались.
- Действия — через RPC сервисов, как в 025; каждое опасное действие требует ключ доступа и пишется в журнал.
- Интерфейс без внешних зависимостей (CSP), вёрстка в стиле сайта, тексты на русском.
- Раздел Premium убрать (ADR 0041).

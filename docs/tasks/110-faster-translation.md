# 110. Перевод быстрее: другая модель и перевод по предложениям

- Статус: открыта, отложена владельцем (2026-11-17: «как будет время, вернёмся»).
- Решение: будет новое ADR, заменяющее разделы ADR 0064 о модели и лицензии.
- Зависит от: 101 (перевод сообщений, `pkg/translate`, сервис `translate`).
- Материалы: `docs/research/110-translation-plan.md` (план и порядок замера), `110-translation-models.md` (модели, лицензии, качество со ссылками), `110-translation-speed.md` (модель времени по нашим замерам).

## Почему
Замер на домашнем сервере 2026-11-17 (HY-MT1.5-1.8B `Q8_0`, 4 слота, 6 потоков, i5-13500T): короткое сообщение 0,7–1,5 с, строка 1,3–2,6 с, абзац ~320 знаков 6–12 с (p95), пачка из 20 — 34,9 с, 4000 знаков — 70–86 с с тайм-аутами; память 2,97 ГБ. Порог брифа 101 (абзац ≤ 6 с, пачка ≤ 25 с) не пройден. `llama bench`: tg128 ≈ 17 токенов/с при 4–8 потоках (упор в память), pp512 ≈ 95–102.

После замера владелец решил: перевод выключить, модель с сервера убрать, вернуться позже. 2026-11-17 перевод включался на час и выключен: `TRANSLATE_URL` пустой, контейнера и образа `pluma-translate` дома нет. Код задачи 101 остаётся на сервере и в клиентах; без движка клиенты перевод не предлагают (`translations_*_enabled` = `disabled`).

## Что сделать (из плана)
1. **Hy-MT2-1.8B** (Tencent, Apache-2.0 по карточке модели — снимает исключение ЕС/UK/Кореи и раскрытие §3(e) лицензии HY-MT1.5): профиль `hy-mt2` в `pkg/translate`, образ с официальным GGUF.
2. **Квантование** `Q4_K_M` или своё `Q5_K_M` вместо `Q8_0`; **привязка к ядрам P** в оверлее.
3. **Перевод длинного текста по предложениям параллельно** на свободных слотах (`scheduler.go`, `markup.go`): абзац ~4–5 с вместо 6–12 (оценка).
4. **Замер:** скорость дома (`TestBench`), качество на CachyOS — chrF++ на FLORES-200 devtest для ru↔en, uk→ru, kk→ru, en→kk против HY-MT1.5 `Q8_0`. Правило выбора: самое лёгкое квантование, у которого chrF++ ни в одном направлении не ниже больше чем на ~1 пункт, доля сохранённых тегов не ниже, нет зацикливаний, а время укладывается в порог.
5. Гибрид с Firefox Translations (Bergamot, 0,1–0,5 с на сообщение) — только если пункт 3 не проходит порог и найдена лицензия весов моделей.

Все цифры скорости кандидатов — оценки по модели времени, не замер.

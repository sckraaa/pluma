# 076. Экраны кода входа через Telegram

- Статус: в работе
- Зависит от: 073 (коды через аккаунт Telegram, ADR 0044).
- ADR: 0044, 0025 (дополняется: свои строки в серверных языковых пакетах).
- Исследование: `076-research/` (планы по клиентам и серверу, с адресами в исходниках).

## Проблема (владелец, 2026-11-10)
Код не пришёл: у получателя в Telegram «Кто может найти меня по номеру» закрыт, и аккаунт рассылки не находит его (`importContacts` вернул `user_id = 0`, сервис ответил `no_telegram`). Клиенты при этом говорят неправду:
- после запасного пути пишут «Мы отправили SMS»;
- при доставке через Telegram пишут «код в Pluma на другом устройстве»;
- «Не получили код?» на iOS и Android ведёт в поддержку Telegram (`sms@telegram.org`, `auth.reportMissingCode`).
Повторить через Telegram после смены настройки нельзя: повторный запрос уходит администратору.

## Решение владельца
Вариант «В», красиво, в родном стиле Telegram, без топорных подсказок: объяснение, «Отправить ещё раз», администратор, кнопка в настройки Telegram.

## Дизайн
Каждый способ доставки получает свой тип ответа, чтобы текст был правдой.

| Случай | Ответ сервера | Экран |
|---|---|---|
| Код в другой сессии Pluma | `auth.sentCodeTypeApp` | родной экран, как сейчас («в Pluma на другом устройстве») |
| Код ушёл в Telegram | `auth.sentCodeTypeFragmentSms{url = tg://resolve?domain=<аккаунт рассылки>}`, `next_type` sms | вёрстка экрана Fragment: «Проверьте Telegram», текст «код отправлен в Telegram сообщением от …», кнопка «Открыть Telegram» (чат с аккаунтом), ссылка «Не пришёл код?» |
| Telegram не доставил или «Не пришёл код?» | `auth.sentCodeTypeSms`, `next_type` sms с таймером | та же вёрстка: «Код не дошёл до Telegram», путь «Настройки → Конфиденциальность → Номер телефона → Кто может найти меня по номеру → Все», кнопка «Открыть настройки Telegram» (`tg://settings/phone_privacy`), ссылка «Отправить ещё раз», строка «без Telegram код выдаст администратор, введите его здесь» |

- Почему Fragment. У экрана Fragment во всех клиентах, кроме Web, есть крупная заливная кнопка под текстом: это родной элемент Telegram, его вёрстка, цвета и анимации. В Pluma анонимных номеров Fragment нет, этот тип свободен.
- Кнопки открывают настоящий Telegram (Pluma не перехватывает `tg://`). Если Telegram не установлен (Android, iOS), кнопка скрыта; Desktop и Web проверить это не могут, кнопка показывается всегда.
- Пути в поддержку Telegram с этих экранов убираются.

### Сервер
- Доставка через Telegram отвечает FragmentSms с адресом чата аккаунта рассылки; имя аккаунта сервис `codes` сообщает в `/v1/state` (TDLib `getMe`).
- `auth.resendCode`:
  - из «Проверьте Telegram» — в запасной экран без новой попытки;
  - из запасного — новая попытка через Telegram, успех даёт «Проверьте Telegram», неудача — снова запасной;
  - число попыток на запрос ограничено, лимиты отправителя прежние.
- Код администратора остаётся действительным после повторной доставки через Telegram (сейчас перезаписывается — ошибка).
- `auth.reportMissingCode` — настоящая реализация вместо заглушки (старые сборки).
- Свои строки клиентов для iOS, Desktop и Web — в серверных языковых пакетах (дополнение к ADR 0025): без этого русский пользователь видит английский.

### Аккаунт рассылки
Имя пользователя аккаунта — `pluma_chat` (владелец, 2026-11-10): кнопка «Открыть Telegram» ведёт на `tg://resolve?domain=pluma_chat`. Сервис `codes` читает имя сам (`getMe`) после выката своей новой версии.

### Порядок выпуска
Сначала клиенты, затем сервер: старые сборки на новом типе показали бы текст про Fragment (кнопка у них всё равно открывает чат в Telegram).

## Тексты (единые для всех клиентов)
Ключи у каждого клиента свои (Android `PlumaLogin*`, iOS `Pluma.Login.*`, tdesktop `lng_pluma_code_*`, Web `Pluma.Code.*`), тексты одни. «Telegram» в них — настоящий Telegram, переименование в Pluma их не трогает. Путь в настройках — дословно надписи приложения Telegram на этом языке (`PrivacySettings`, `PrivacyPhone`, `PrivacyPhoneTitle2`, `LastSeenEverybody`).

Языки: все 37 языков серверных пакетов Telegram, для всех четырёх клиентов. Android встраивает 10 и получает остальные с сервера (пакет `android` в `own.json`, там же те 10, иначе английский перекрыл бы встроенный текст). Надписи пути в настройках взяты дословно из снимка пакетов Telegram 2026-11-10: `android`, а для bg, el, lt, sl, которых нет в `android`, — `tdesktop`. Переводы 27 новых языков носителями не вычитаны.

## Что проверить
Скриншоты всех трёх экранов в Android (эмулятор), iOS (симулятор), Desktop (CachyOS), Web (браузер) против локального стенда с заглушкой отправителя; затем на проде с настоящим аккаунтом.

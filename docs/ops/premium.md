# Premium

По умолчанию Premium нет ни у кого. Администратор выдаёт его отдельным пользователям: бессрочно или на несколько месяцев (ADR 0016, задача 014). Оплаты нет.

## Команды

Выдача и снятие идут через сервис пользователей: он сбрасывает кэш и сообщает устройствам пользователя. Поэтому `grant` и `revoke` запускаются там, где виден etcd стека, то есть внутри контейнера bff.

```bash
docker compose exec bff ./pluma-admin -f ../etc2/bff.yaml premium grant +79991234567             # бессрочно
docker compose exec bff ./pluma-admin -f ../etc2/bff.yaml premium grant +79991234567 -months 3   # на 3 месяца
docker compose exec bff ./pluma-admin -f ../etc2/bff.yaml premium revoke +79991234567
docker compose exec bff ./pluma-admin -f ../etc2/bff.yaml premium list
```

- **Сроки.**
  - `-months N` добавляет месяцы к действующему сроку. Если срока нет или он истёк, месяцы считаются от сейчас.
  - `grant` без `-months` делает Premium бессрочным.
  - Команда печатает состояние после изменения.
- **`list`** показывает, у кого есть Premium и до какого времени, и читает только базу.
- **Истечение срока.** Воркер сервиса biz раз в минуту снимает Premium с истёкшим сроком. Устройства узнают об этом так же, как о `revoke`. Ошибки воркера считает метрика `user_premium_expiry_errors_total`; сам он повторяет попытку на следующем проходе.

## Что даёт Premium

Устройства пользователя получают своего пользователя с флагом `premium` (`updates{updateUser}`). Официальный клиент сразу показывает Premium.

| Возможность | Без Premium | С Premium |
|---|---|---|
| Папки чатов | 10 | 30 |
| Чатов в папке (включённых, отдельно исключённых) | 100 | 200 |
| Теги папок | `PREMIUM_ACCOUNT_REQUIRED` | можно включить |
| «Все чаты» | всегда первые | на любом месте |
| «Писать могут только контакты и Premium» | `PREMIUM_ACCOUNT_REQUIRED` | можно включить |

**Настройка «только контакты и Premium»** (`new_noncontact_peers_require_premium`). Писать такому пользователю могут:
- его контакты;
- те, с кем у него уже есть личный чат;
- пользователи с Premium.

Остальные получают `PRIVACY_PREMIUM_REQUIRED` при отправке, а клиент показывает это вместо поля ввода.

**Premium-функции, которых на сервере нет**, от выдачи флага не появляются. Это расшифровка голосовых, перевод, эмодзи-статусы и т. п.

## После снятия
- **Папки.** Папки сверх лимита остаются, клиент их блокирует. Новых сверх лимита не создать. «Все чаты» снова первые.
- **Теги и настройка «только контакты и Premium»** не действуют. Выбор пользователя сохранён и снова заработает, если Premium вернуть.

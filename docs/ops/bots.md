# Боты

Боты — обычные аккаунты MTProto (ADR 0043). Создаёт их администратор через `pluma-admin`, клиенты и библиотеки (Telethon, TDLib, Pyrogram) входят токеном через `auth.importBotAuthorization`. Отдельный сервер Bot API и мини-приложения пока не сделаны.

## Развёртывание
Миграция `migrate-20261109-bots-core.sql` применяется службой миграций. Новых переменных нет. Вызовы `RPCBots`, `RPCBotMenuButton`, `RPCInlineBot`, `RPCDeepLinks` уже разведены в `session.yaml`.

## Команды
В Docker: `docker compose exec teamgram /app/bin/pluma-admin -f /app/etc2/bff.yaml bot <команда>`.

- `bot create <имя_bot> <название> [-owner <телефон>]` — создаёт бота и один раз печатает токен. Имя: 5–32 символа, латиница, цифры, `_`, начинается с буквы, заканчивается на `bot`. Владелец (`-owner`) сможет менять имя и описание бота из клиента.
- `bot token <имя_bot>` — выдаёт новый токен: старый перестаёт работать сразу, уже вошедшие сессии бота завершаются. Если команда сообщила, что сессии не завершены, запустите её ещё раз и используйте токен из последнего запуска.
- `bot list` — список ботов, без токенов.
- `bot set <имя_bot> [-privacy on|off] [-groups on|off] [-inline <подсказка>] [-inline-geo on|off]`:
  - `-privacy off` — бот читает все сообщения групп (по умолчанию только команды, ответы ему и служебные сообщения; бот-админ видит всё);
  - `-groups off` — бота нельзя добавить в группы;
  - `-inline "Поиск..."` включает инлайн-режим, `-inline " "` (пробел) выключает.

Токен — секрет: в базе лежит только его хэш, показать его ещё раз нельзя. Передавайте его тому, кто запускает бота, надёжным каналом.

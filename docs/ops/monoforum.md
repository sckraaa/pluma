# Личные сообщения каналу

ADR 0055, задача 084.

## Что это
Владелец вещательного канала (или админ с правом менять информацию) включает «Личные сообщения» в настройках канала. У канала появляется отдельный чат — монофорум: подписчик пишет в него каналу, админы канала с правом «Управлять личными сообщениями» видят переписку с каждым подписчиком отдельно и отвечают от имени канала. Подписчик видит только свою переписку.

Сообщения бесплатны: цену в звёздах сервер не принимает (`STARS_AMOUNT_INVALID`), клиенты её не предлагают, пока `stars_paid_messages_available` в app config равен `false`.

Предложенные посты (кнопка «Предложить пост» в чате с каналом) пока не обслуживаются: отправка отвечает ошибкой.

## Кто что видит
- Права читаются из канала в момент запроса. Сняли у админа право «Управлять личными сообщениями» или он вышел из канала — чужую переписку он больше не получает ни в истории, ни пушами. Строк в `channel_participants` у монофорума нет.
- Подписчик, которого забанили в канале, теряет доступ к своему чату с каналом. Посторонний может написать публичному каналу, не вступая; закрытому — только участник.
- Выключение личных сообщений оставляет переписку: писать нельзя никому, включение возвращает те же чаты.
- Удаление канала удаляет и монофорум.

## Данные
- `channels`: `broadcast_messages_allowed` (у канала), `monoforum` (строка монофорума), `linked_monoforum_id` (у обеих сторон).
- `channel_messages.saved_peer_id` — подписчик, в чьём чате сообщение; `send_as_id` — канал у ответов админов, `sender_user_id` — кто из админов ответил.
- `channel_monoforum_sublists` — чаты подписчиков: последнее сообщение, отметки прочтения обеих сторон, отметка «непрочитано».
- `channel_monoforum_drafts` — черновики админов по чатам.

Посмотреть переписку канала `<id>`:
```sql
SELECT s.peer_id, s.top_message, s.read_inbox_max_id, s.read_outbox_max_id
FROM channels c JOIN channel_monoforum_sublists s ON s.channel_id = c.linked_monoforum_id
WHERE c.id = <id> ORDER BY s.top_message DESC;
```

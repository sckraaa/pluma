# 0010. Сборка клиентов в облаке

- Статус: accepted (владелец согласовал публичные репозитории клиентов 2026-10-21)
- Дата: 2026-10-21 (по `docs/audit/05-cloud-builds.md`)

## Контекст
Владелец не хочет зависеть от своего железа (Mac, ПК). Нужны автономные, дешёвые сборки с кэшем и без перезапуска с нуля после поздней ошибки.

## Решение
- Четыре **публичных** репозитория клиентов (iOS, Android, Desktop, Web): `UPSTREAM_REF` (тег с layer 228), `patches/`, `ci/apply-patches.sh` с проверкой каждой замены, `ci/*.sh`, не зависящие от конкретного CI. Публичность допустима: GPL и так требует открыть исходники получателям; адрес сервера, публичный RSA-ключ и api_id — не секреты.
- Стандартные GitHub-hosted раннеры: для публичных репо бесплатны без лимита минут (macOS M1 3 CPU / 7 ГБ; Linux и Windows 4 CPU / 16 ГБ).
- Jobs: preflight (секунды: Xcode/NDK, Metal toolchain, профили и ключи, layer = 228, отпечаток RSA) → build с кэшем (Bazel disk cache / ccache / Gradle в `actions/cache`, сохранение даже при падении) → sign → publish на VPS. «Re-run failed jobs» перезапускает только упавший job.
- Еженедельная сборка-«канарейка» держит кэши живыми и рано ловит изменения образов раннеров.
- Секреты подписи — только в environment secrets с обязательным ревьюером; никаких `pull_request_target`; actions закреплены по SHA. Готовые IPA/APK не выкладываются в публичные artifacts — сразу на VPS (или шифруются).
- Резерв: Codemagic (500 бесплатных минут macOS M2/мес), Depot (платно, быстрее).

## Ожидаемое время
iOS: холодная 55–70 мин, тёплая без изменений 4–10 мин, после правки сетевого ядра 45–55 мин. Android (1 ABI): 25–40 / 8–14 мин. Desktop Linux: 15–20 мин (после разового образа тулчейна). Web: 2–6 мин.

## Последствия
- Стоимость $0/мес (+ Apple Developer Program $99/год, нужен в любом случае).
- Код, патчи и логи сборок видны всем; адрес сервера публичен.
- Лимит кэша 10 ГБ на репо и вытеснение через 7 дней без обращений — следим; при нехватке — платное расширение ($0.07/ГБ-мес) или bazel-remote на VPS.

## Рассмотренные альтернативы
- Свой Mac и ПК как self-hosted runners — владелец не хочет привязки к железу.
- Приватные репозитории — ≈ $15–55/мес и более медленные Linux/Windows-раннеры.
- Xcode Cloud — не подходит под Bazel.

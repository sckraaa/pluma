# 0007. Репозиторий как память проекта

- Статус: accepted
- Дата: 2026-10-21

## Контекст
Проект на месяцы, работа идёт короткими итерациями и с перерывами. Знание, которое живёт только в голове или в переписке, теряется.

## Решение
- `docs/project/STATUS.md` — живое состояние: что сделано, что в работе, следующий шаг, известные проблемы. Обновляется в конце каждой задачи и держится коротким.
- `docs/adr/` — решения с обоснованием; `docs/tasks/` — брифы задач (одна задача — одна ветка); `docs/audit/` — отчёты.
- Прогресс измеряется машинно: `tools/apicoverage` → `docs/project/api-coverage.md`; поведение фиксируется тестами (ADR 0002).

## Последствия
Каждая задача заканчивается обновлением STATUS и брифа — небольшая дисциплина взамен потери контекста.

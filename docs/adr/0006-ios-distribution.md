# 0006. Распространение iOS: ad-hoc

- Статус: accepted
- Дата: 2026-10-21

## Контекст
Публикация в сторы не планируется. Владелец подписывает и устанавливает сборки вручную.

## Решение
- Ad-hoc подпись с регистрацией UDID устройств.
- Все App ID, App Groups и профили для расширений (Notification Service, Share, Widget, Intents и т. д.) создаются под одну команду разработчика.
- Push: production APNs (работает с ad-hoc), включая VoIP push.

## Последствия
- Лимит Apple: 100 устройств каждого типа (iPhone, iPad, …) на аккаунт разработчика в год; удалить устройство из списка можно только при годовом сбросе. Учитывать при выдаче доступа.
- Ad-hoc профиль живёт год — продление планируется заранее.
- Запасной путь при упоре в лимит: TestFlight.

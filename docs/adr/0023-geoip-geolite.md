# 0023. GeoIP: MaxMind GeoLite City, обновление без перезапуска, город только при малом радиусе

- Статус: accepted
- Дата: 2026-10-30
- Задача 017 (ребрендинг клиентов; часть «Вход по QR и экран „Устройства“»). Заменяет DB-IP Lite, которую туда поставили пробно.

## Контекст
- **Место сеанса.** authsession находит его по IP в базе MMDB. Его показывают «Устройства» (`account.getAuthorizations`, поле `country`) и сообщение «Новый вход». Читатель — `github.com/oschwald/geoip2-golang` v1.8.0.
- **DB-IP Lite ошибается.** У владельца, вошедшего из Праги, она показала «Děhylov»; Telegram на том же входе показал «Prague, Czechia». Какой базой пользуется Telegram, в источниках не сказано.
- **Сравнение баз** — бриф 017, пункт «Выбор базы GeoIP» в «Ходе работы» (источники прочитаны 2026-10-30). По Чехии:
  - GeoLite City помещает в пределах 50 км 53% адресов по данным MaxMind и 54,2% по независимому GPS-отчёту BigDataCloud;
  - платная DB-IP — 35,1% по тому же отчёту;
  - платная GeoIP City MaxMind — 56%, но её лицензия не разрешает показывать город людям вне компании без отдельной коммерческой лицензии.
- **Условия GeoLite.** База бесплатная, нужны аккаунт, ключ и EULA. Показ пользователям разрешён с атрибуцией MaxMind. Выпуск нужно удалить в течение 30 дней после выхода нового. Выходят выпуски по вторникам и пятницам.
- **Мобильные сети.** Ни одна база не определяет их точно: по данным MaxMind, GeoLite помещает в пределах 50 км 28% мобильных адресов Чехии.

## Решение
1. **База — GeoLite City** (`GeoLite2-City.mmdb`). Тип известен geoip2-golang, код чтения не меняется.
2. **Скачивает её официальный `geoipupdate`** — сервис в `docker-compose-env.yaml`, образ `ghcr.io/maxmind/geoipupdate` v8.0.0, закреплённый по digest.
   - Проверка каждые 12 часов.
   - Ключ — `MAXMIND_ACCOUNT_ID` и `MAXMIND_LICENSE_KEY` в `.env`.
   - Новый файл geoipupdate сверяет по MD5 и ставит на место переименованием.
3. **authsession подхватывает новый файл сам** (`dao/geoip.go`).
   - Раз в 10 минут он сравнивает файл с открытым: inode, время, размер.
   - Новый файл открывается и проверяется. Затем под блокировкой записи он подменяет старый, а старый закрывается.
   - Поиск держит блокировку чтения, пока читает базу. Поэтому закрытая, то есть отображённая из памяти, база не читается никогда.
   - Файл, который нельзя открыть, и пропавший файл оставляют прежнюю базу. Ошибка пишется в лог один раз.
4. **Город — только если `accuracy_radius` ≤ 100 км.** Иначе — только страна (`placeOf`, `maxCityRadius`). У базы без радиуса, например DB-IP Lite, город остаётся. Порог выбран нами.
5. **Атрибуция** — в `NOTICE` и в `docs/ops/deployment.md`. По решению владельца (2026-10-30) в клиентах и на сайте её нет: GeoLite там не упоминается.

## Последствия
- **Порядок выкатки.** Сначала ключ в `.env` и `geoipupdate`, потом authsession с новым путём. Иначе места будут `UNKNOWN`, пока файл не появится.
- **Без ключа** `docker compose -f docker-compose-env.yaml` не запускается, как и без других обязательных переменных. e2e подставляет фиктивные значения: `geoipupdate` там не запускается.
- **Перезапуск authsession** для новой базы не нужен. Ручной скрипт `update-dbip.sh` удалён.
- **«Без города».** Часть мобильных входов покажет только страну. Это честнее, чем город за сотни километров.

## Рассмотренные альтернативы
- **Платная DB-IP IP to Location** (299,90 € в год). Отпадает: в независимом отчёте по Чехии она хуже бесплатной GeoLite.
- **Платная GeoIP City** ($1628 в год). Отпадает: прибавка 3 пункта, а показ города пользователям требует коммерческой лицензии с ценой по запросу.
- **Веб-сервис MaxMind City Plus.** Отпадает: каждый адрес пользователя уходил бы в MaxMind (США), и нужен HTTP-клиент.
- **Перезапуск authsession по таймеру хоста.** Отпадает: обращения во время перезапуска завершаются ошибкой, а таймер — ещё одна вещь на хосте вне compose.
- **Свой скрипт загрузки на curl.** Отпадает: протокол — метаданные, MD5, перенаправление на R2 — уже реализован в официальном клиенте.

# ROADMAP

Этап считается закрытым, когда его фичи проходят сравнительные тесты (ADR 0002) и работают в iOS, Android и Web (ADR 0001). Порядок внутри этапов уточняется после аудита.

## Этап 0 — фундамент
Аудит завершён: `docs/audit/00-summary.md` (ядро оставляем и глубоко чиним). Задачи 001–010 в `docs/tasks/`:
безопасность P0/P1, долговечные счётчики, надёжная доставка, развёртывание и бэкапы, тесты и CI, конвейер сборки клиентов, сравнительные тесты, seq/getDifference, push.

## Этап 1 — каналы и супергруппы
Модель данных с `pts` на канал, `updates.getChannelDifference`, участники, права, админы, форумы/топики.

## Этап 2 — повседневные функции
Реакции, стикеры и эмодзи, отложенные сообщения, автоудаление, опросы, черновики, папки, темы, обои, поиск.

## Этап 3 — секретные чаты и боты
Секретные чаты; Bot API (собственный сервер Bot API поверх нашего MTProto).

## Этап 4 — звонки
1:1 (tgcalls + TURN), затем групповые звонки, экран, вебкамеры (ADR 0004).

## Постоянно
Обновление layer вслед за клиентами; нагрузочные и chaos-тесты; бэкапы с проверкой восстановления.

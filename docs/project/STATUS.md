## Известные проблемы и риски
- **Остаточные риски безопасности до задачи 008:** нет 2FA (подбор 6-значного кода ко всей группе из 100 номеров — порядка 3,6% в год при постоянной атаке); кто знает номер из allowlist, может держать владельца в `FLOOD_WAIT` (снимается `pluma-admin login-unblock`); нет recover в `runLoop` session; нет лимитов по числу соединений с IP и верхней границы `expires_in`; etcd/Kafka без аутентификации и нет TLS между сервисами (порты закрыты снаружи). Legacy `httpserver` со старым handshake не запускается и не публикуется — удалить или переписать в 008.
- Истёкшие temp-ключи не удаляются из БД, `auth.dropTempAuthKeys` не реализован (задача 008).
- Формат inbox-событий и число партиций изменились — при обновлении группы и топики пересоздаются (`docs/ops/user-state.md`).
- `messages.deleteChatUser` удаляет строку диалога исключённого участника, а его сообщения группы остаются (поведение апстрима; в Telegram чат у исключённого остаётся в списке).
- Свежие клиенты на layer 229–232; держим клиентов на 228 (ADR 0008). Обновление layer зависит от upstream `teamgram/proto` — генераторы TL не открыты.
- Каналы: 1 из 74 методов; звонки: 0 из 45; push: заглушка.
- Клиенты пока выглядят как Telegram: логотип, «Telegram» в заголовке и на приветствии, пункты Premium/Business/FAQ. До раздачи — ребрендинг (иконки патчем, строки через langpack сервера).
- `help.getNearestDc` не знает страну клиента (нет GeoIP-базы; клиент берёт страну SIM). `config.json` сервера ещё ссылается на teamgram.io (`me_url_prefix`) и `apv2.stel.com`. `auth.sentCode` говорит «SMS», хотя код приходит из `pluma-admin` или в приложение.
- Web K: у собственного сообщения в «Избранном» отправивший браузер показывает бейдж непрочитанного «1», второй — нет. Похоже, отправителю приходит его же сообщение как входящее; Telegram своё в «Избранном» непрочитанным не считает.
- `help.getAppConfig` — пустая заглушка апстрима (задача 015): Web K не создаёт ни одной папки («limit of undefined folders»), Android берёт свои значения (Premium — 20 папок вместо 30), экраны покупки Premium ведут в никуда. Лимит закреплённых чатов сервер не проверяет.
- Web K в настройках показывает у самого пользователя «last seen Jan 1, 1970»; служебный аккаунт и его сообщения (код входа, новый вход) называются «Teamgram» — к ребрендингу.
- `help.getCountriesList` без `prefixes` (Android их не использует) — проверить на iOS и Desktop.
- Интеграционный `TestConcurrentOperations` (`pkg/userbox`) один раз упал при полном прогоне с `-p 4` (тест шёл 111 с вместо 14); повторные прогоны зелёные. Причину не установили — при повторе сохранить вывод.
